## Что практикую

- Подбор позитивных, граничных и ошибочных входных данных.
- Оформление баг-репортов, анализ влияния и отделение наблюдений от предположений.
- Проверку HTTP-статусов, заголовков и содержимого ответа.
- Page Object, явные ожидания и независимый запуск UI-сценариев.
- Параметризованные модульные тесты и читабельные проверки.
- Настройку сборки через Gradle, HTML-отчёты.
- Основы Java, ООП и устройство REST API на Spring Boot с PostgreSQL.

В README проектов описаны контекст и ограничения проверок, а для запускаемых проектов — требования к окружению и команды запуска. Работы учебные; тексты заданий и закрытые учебные материалы не публикуются.
